# Acuerdo de contribución (CLA)

Al abrir un pull request en este repositorio, declarás que:

1. **El aporte es tuyo** (o tenés permiso para aportarlo) y no infringe derechos
   de terceros.
2. **Lo licenciás bajo Apache-2.0**, igual que el resto del repo.
3. **Le das además a DataDruida** una licencia perpetua, mundial, gratuita,
   irrevocable y no exclusiva para usar, modificar, sublicenciar y distribuir
   tu aporte **bajo otras licencias**, incluso en productos comerciales.
   Esto existe para que DataDruida pueda cambiar la licencia del proyecto en el
   futuro sin tener que pedirle permiso a cada persona que aportó código.
4. **Seguís siendo el autor.** Podés usar tu aporte donde quieras.
5. Si tu empleador tiene derechos sobre lo que programás, **conseguiste su
   permiso**.

El aporte se entrega "tal cual", sin garantías.

En el pull request vas a ver una casilla para aceptarlo. Sin esa casilla
tildada no podemos mergear.
